# Дизайн админки

Админка — внутренняя CRM/TMS для Dispatcher, Admin, Accounting и Safety. Исходный визуальный ориентир: тёмная navy-шапка, светлый рабочий фон, крупные белые карточки, синий основной акцент и зелёный для положительных операционных и финансовых статусов.

## Палитра

Единственный источник цветов — [`apps/admin/src/styles/theme.css`](../apps/admin/src/styles/theme.css). В нём сначала определены брендовые токены `--color-*`, затем семантические `--surface-*`, `--text-*`, `--accent-*`, `--success` и `--warning`.

Компоненты используют только семантические токены. Поэтому для смены брендинга достаточно поменять значения palette в одном файле, а не искать цвета по JSX и CSS.

## Первый экран

`Dispatcher workspace` показывает очередь Loads, метрики, карточку нового Rate Confirmation и готовность данных к review. Это не калькулятор из референса: структура и цветовой язык сохранены, а содержание заменено на реальный workflow TMS.

Формы используют тот же визуальный язык: uppercase label, сгруппированные переключатели, крупные поля ввода с синим focus-state, валютный suffix и мягкий контекстный callout. Базовые классы находятся в `apps/admin/src/styles/app.css`; новые формы должны переиспользовать их, а не добавлять произвольные цвета.

Запуск локально:

```bash
pnpm --filter @312kg/admin dev
```
